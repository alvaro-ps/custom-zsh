# Jira ticket creator

Create meaningful Jira tickets

## When to Use This Skill

Whenever you are asked to create Jira tickets.

## Core Concepts

- Make sure to include a detailed description with a definition of done included
- Write a `[Written by AI]` before whatever ticket description you write, so that people know the description was created by you.
- Make sure that any details required are properly filled in. This may need you to check what details
- If the ticket belongs to an epic, be sure to include the epic in the parent epic detail.
- Be sure to include the Squad detail. If not mentioned it in the ask, do ask yourself which squad should the ticket belong to.
- The ticket should include a number of story points too. Nudge towards getting that number if not specified.

## Data Platform squad specifics
- If the ticket belongs to the Data Platform squad, create it in the PIP project.

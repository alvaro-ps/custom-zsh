# Jira ticket creator

Create meaningful Jira tickets

## When to Use This Skill

Whenever you are asked to create Jira tickets.

## Core Concepts

- Make sure to include a detailed description with a definition of done included. Definition of done can be skipped if explicitly stated.
- Write a `[Written by AI]` before whatever ticket description you write, so that people know the description was created by you.
- If the ticket belongs to an epic, be sure to include the epic in the parent epic detail. This is mandatory, so make sure it happens. If you are creating both epic and tickets together, create the epic first so that you have its reference when creating the tickets.
- Make sure that the Squad detail is included.
- Make sure that any details required are properly filled in. This may need you to check what details
- The ticket should include a number of story points too. Nudge towards getting that number if not specified.
- If any mandatory business field is missing, ask exactly one bundled question covering all missing items.

## Data Platform squad specifics
- If the ticket belongs to the Data Platform squad, create it in the PIP project.
